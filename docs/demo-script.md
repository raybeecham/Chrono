# Chrono three-minute demo script

## Before the timer

- Start from a fresh page load so Timeline Integrity reads 100%.
- Leave **Sound on** for the synthesized dial tone, number dialing, and carrier handshake; use **Skip connection** if the timer is tight.
- Have the app running and decide whether the recording will show **GPT-5.6 live** or **Demo fallback**. Both preserve the integrity demo; live mode needs a configured server-side key.
- Keep the browser large enough to show the desktop icons and integrity meter. Do not open an external source link during the timed run.

## 0:00–0:15 — Enter the date

**Click:** **Enter December 1998** and let the temporal modem complete. Briefly point out the original ChronoClip helper when the desktop appears.

**Say:** “Chrono turns a historical date into a place you can explore. This prototype is one focused vertical slice: Austin, Texas, on Friday, December 4, 1998.”

## 0:15–0:50 — Show evidence, not just atmosphere

**Click:** **Time Capsule** → **Endeavour leaves Earth** → **View 1 source**.

**Show:** The NASA source card, including its publisher, date, summary, and **Open source** link. Close the drawer with **×**, then click the **Games** category.

**Say:** “The capsule contains 20 interactive facts across eight categories, grounded in 10 curated sources. Documented claims link to evidence. Representative details are period-informed synthesis. Fictional details—like Sam’s save file—are labeled as atmosphere, not history.”

## 0:50–1:10 — Browse the reconstructed web

**Click:** **The Internet** → **NASA Shuttle Mission — live today**.

**Say:** “ChronoNet is interactive rather than a screenshot: it has browser history, a human-edited directory, a fictional GeoCities page, a representative Ask Jeeves search, and this documented STS-88 page with the NASA record linked.”

## 1:10–2:25 — Talk to 1998 and disturb the timeline

**Click:** **Talk to Sam**.

1. Select `What websites do you use?`

   **Say while the reply arrives:** “Sam is a fictional 17-year-old with a consistent voice and memory inside this session. His knowledge boundary is December 4, 1998.”

2. Type `Can I connect this laptop to the Wi-Fi?` and click **Send**.

   **Show:** **Possible anachronism** and the small integrity decrease.

   **Say:** “Subtle future language is classified as probable contamination.”

3. Select `Have you heard of an iPhone?`

   **Show:** **Temporal contamination**, the larger integrity decrease, and ChronoClip’s warning-specific reaction.

   **Say:** “An obvious future product is definite contamination, so Sam reacts in character and the score falls further.”

4. Select `Have you heard of an iPhone?` again.

   **Show:** The repeat notice and unchanged integrity score.

   **Say:** “The engine groups aliases under canonical concepts. It still recognizes a repeat, but it never penalizes the same concept twice.”

## 2:25–2:52 — Explain the OpenAI and reliability architecture

**Point to:** The **GPT-5.6 live** or **Demo fallback** badge and the conversation transcript.

**Say:** “The deterministic server engine owns the three tiers and repeat-safe score. GPT-5.6 gets that assessment and transcript through the Responses API, then returns Sam’s structured period reply; the server verifies both decision and reply safety. Missing or failed API access uses deterministic Sam; transport failures offer nonduplicating Retry; the key stays server-side. Codex accelerated the build, tests, and polish, but is not a runtime dependency.”

## 2:52–3:00 — Close

**Show:** Sam, the changed integrity meter, and the reconstructed desktop together.

**Say:** “Chrono combines a world, a person, evidence, and consequences in one date you can inhabit. Don’t read history. Live it.”

## If live mode fails during the demo

Continue speaking while the deterministic response appears. Point to **Demo fallback** and say: “This is the reliability design in action—the character becomes deterministic, but the historical boundary, classification, explanation, score, and repeat protection remain intact.” If the browser cannot reach Chrono’s own API route and shows **Retry**, select it once; the original user line will not be duplicated.

## Optional game flourish

If you have another 10–15 seconds, open **Snake '98** and point out that ChronoClip switches to a game-specific tip. Select **Start**, then use the arrow keys or on-screen direction pad to collect the red pixel. Say: “Even the downtime is interactive—this is a dependency-free, keyboard- and touch-friendly recreation built into the desktop.” The game pauses automatically when its window is minimized.

## Optional expanded-desktop flourish

Open **Time Missions** to show that NASA, GeoCities, Sam, Snake, and integrity events are tracked from real interactions. If all five are complete, show the **Certified Time Traveler** session badge. For a lighter moment, open **Inbox ’98**, play one original **ChronoAmp** loop, inspect Sam in the fictional **Buddy List**, or launch **Screen Saver**. Five clicks on the taskbar clock—or the classic up, up, down, down, left, right, left, right, B, A sequence—reveals the hidden Developer Vault.
