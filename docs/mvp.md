# Chrono MVP

## Demo promise

A judge can enter December 4, 1998, experience a period-specific computer interface, explore an early-web reconstruction, speak with a teenager who only knows what was knowable at the time, and visibly damage timeline integrity by mentioning future technology.

## Three-minute demo path

1. Open the cinematic landing page.
2. Choose **The Early Web, 1998**.
3. Watch the temporal modem connection sequence.
4. Open **The Internet** and show the era-specific web experience.
5. Open **Talk to Sam** and ask, “What websites do you use?”
6. Ask, “Have you heard of an iPhone?”
7. Show the contamination warning and falling Timeline Integrity score.
8. Briefly show the repository, OpenAI route, deterministic demo fallback, and Codex build log.

## Must-have scope

- One excellent era: December 1998.
- Responsive, accessible interface.
- GPT-5.6 period-aware character.
- Structured temporal-contamination output.
- Offline fallback for reliable judging.
- Clear setup instructions and deployable repository.

## Explicit non-goals for the first submission

- User accounts.
- Persistent databases.
- More than one fully interactive era.
- Unbounded alternate-history simulation.
- Claims that AI dialogue is a primary historical source.
